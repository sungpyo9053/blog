# 피지컬 AI 사이트 공개 개편

2026-09-17. 사용자 승인: 사이트 개편.

## 적용 범위

- 기존 준비된 physical-home 템플릿·로봇 팔 이미지·학습 경로를 공개 WordPress에 배포.
- 홈 제목을 피지컬 AI, 기초에서 실습까지로 정리. 학습 분야 네 개와 정확한 준비 중 표시.
- 데스크톱·모바일 메뉴, 콘텐츠 탐색 탭, 푸터와 검색 소개를 피지컬 AI 방향으로 통일.
- 공개 페이지97(소개),100(편집 원칙)의 내용과 사이트 설명 갱신. AI 사용·운영 책임·문의·개인정보 링크 유지.
- WordPress 운영 카테고리는 이전 운영 노트로 유지. 게시글 삭제·본문 수정·공개 전환 없음.
- 브리핑에 중복 출력되던 옛 홈 소개 제거. 브리핑 자체와 기존 URL 유지.
- Kadence가 이미 main을 여는 환경에서 새 홈의 중첩 main을 제거.

## 확인

- 실제 Chrome에서 공개 홈·소개·브리핑을 확인했다.
- 390×844 뷰포트에서 메뉴 열기/닫기, 학습 경로 이동, hero 이미지 로딩, 가로 넘침 없음 확인.
- 홈 H1 한 개, main 한 개. 학습 링크 이동 후 제목이 고정 메뉴 아래에 보임.
- 홈·소개·편집 원칙·기초 카테고리·REST 카테고리·기존 글·진단 도구·브리핑 HTTP200.
- 공개 글이 없는 학습 분야는 준비 중이다. 실제 iPhone Safari 검증이나 새 글 발행 성공을 뜻하지 않는다.

## 복구

WordPress 호스트 `/var/backups/huntlab-ui-20260917/`에 기존 UI 플러그인 압축본과
페이지97·100 및 blogdescription의 변경 전 JSON을 비공개 권한으로 보존했다.
일회성 페이지 적용 스크립트는 기존 백업이 있으면 재실행을 거부한다.
롤백이 필요하면 해당 두 플러그인 및 두 페이지·사이트 설명만 복원하며 DB 전체를 덮어쓰지 않는다.
