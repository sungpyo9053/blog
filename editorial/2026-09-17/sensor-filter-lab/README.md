# 센서 필터 교육용 통제 실험

Python 3.12 이상, 외부 패키지 없음. 실제 센서·로봇·물리 엔진을 실행하지 않는다.
이 폴더를 내려받고 폴더 안에서 실행한다.

```sh
python3 --version
python3 sensor_filter.py
python3 -m unittest -v
python3 sensor_filter.py --invalid-window 0
```

마지막 명령은 입력 검증 대조군으로 의도적으로 종료 코드 2를 반환한다.
앞의 실험과 테스트 명령은 종료 코드 0이어야 한다.

첫 실험은 참값 1m에 +0.2/-0.2m가 번갈아 붙는 고정 배열이다. 모든 창 크기의
RMS는 같은 36개 위치(인덱스 4~39)에서 구한다. 확률 표본·실측 센서 오차가 아니다.
별도 무잡음 계단은 인덱스20부터 0→1m로 바뀐다. 현재/과거 값만 평균하고,
0.9m 이상이 되는 첫 표본까지 걸린 시간을 10ms 표본 간격으로 환산한다.
시작 구간의 창이 덜 찬 결과는 None이며 0으로 채우지 않는다.

예제 데이터·구현·테스트는 이 글을 위해 작성했다. 일반적인 센서 성능이나
실시간 안전성을 증명하지 않는다.
