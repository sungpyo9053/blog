# 11/28 직원 회의 — "구글이 우리 글을 더 많이 색인하고 더 자주 보여 주게 하려면" (21시대)

사용자 지시: ① "글이 퀄리티가 좋으면 많이 들어온다가 아니고, 무조건 구글이 우리 글을 어떻게 색인을 많이 해 주고 자주 보여 주나가 관건. 팀원들이랑 회의하고 재판까지 해서 반영." ② "각 언어마다 특징이 있으니 언어별로 전략을 다르게 가져가자."
자료: meeting-1128-facts.md(우리 숫자), google-indexing-official.md(구글 공식 문서만). 8명 모두 Claude가 역할로 맡음.

## 1. 진단 (직원별 발언)
- **[조사]** 구글 공식 문서가 꼽는 원인 중 기술 오류를 빼면 남는 것은 "콘텐츠 품질"과 "고유성·인기도"다. 근거는 7440203, 크롤링 예산 가이드, how-search-works다. 대량 생성 정책은 "가치 없이 많은 페이지를 만들면" 걸리고, 기준은 AI냐가 아니라 고유 가치다. 사이트 전체 신호도 공식적으로 있다. 색인 요청·사이트맵·lastmod는 발견만 돕고 색인을 보장하지 않는다. 12월 업데이트는 11/24 사전 예고만 된 상태다(배포 시작은 「미확인」).
- **[총괄]** 우리 숫자도 같은 쪽을 가리킨다. KO는 11월 3주 동안 147편(하루 약 7편)을 공개했고 생활 글 색인은 186편 중 5편(2.7%)이다. EN은 내내 하루 1편이고 68편 중 18편(26%)이 남았다. 구글봇은 하루 72회에서 9회로 줄었다. 기술 오류는 0이다.
- **[기획]** 같은 "2026 ○○ 계산기 총정리" 틀이 수십 편이라 구글 눈에는 비슷한 페이지 묶음이다. 11/28 비교에서 "틀 자체"가 원인이라는 증거는 없었다. 그러나 "속도 + 비슷한 주제 반복"은 정책 문구와 겹친다.
- **[디자인]** 화면·속도 문제는 없다(CLS·광고는 기존 점검 그대로). 화면은 지렛대가 아니다.
- **[개발]** 사이트맵·robots·canonical·응답 코드는 모두 정상이다. 기술로 더 할 것은 없다. Indexing API는 허용 범위 밖이다.
- **[검수]** 11/26 GSC 요청 8편은 회복 0이었고, 11/20~23 색인 글 갱신도 지켜 주지 못했다. "요청·갱신으로 색인을 되돌린다"는 가설은 실패로 판정한다.
- **[마케팅]** 공식 문서가 새 사이트에 권하는 것은 홍보, 즉 사람들이 알고 링크하게 만드는 것이다. EN은 GitHub·ROS Discourse라는 실제 질문 공간이 있다(규칙상 허용, AI 표시). KO는 허용된 외부 채널이 사실상 없다(네이버 블로그 금지, 새 채널은 사용자 결정).
- **[CS]** 댓글 실제 질문은 0이다. 사람 반응 신호가 없다.

## 2. 언어별 특징
| | KO (생활 계산기·요금·지원금) | EN (ROS 2 문제 해결·실측) |
|---|---|---|
| 색인 유지 | 2.7% (5/186) | 26% (18/68) |
| 공개 속도 | 11월 하루 약 7편 | 하루 1편 |
| 고유성 | 공식 표를 옮긴 글이 많고, 경쟁 페이지(정부 계산기·블로그)도 같은 값 | Docker 실측 출력 = 우리만 가진 것 |
| 경쟁 | 정부 공식 계산기 + 수많은 블로그 | 질문 수요(SE·GitHub 이슈)에 답이 드묾 |
| 다른 검색엔진 | 네이버·다음 비중 큼(Yeti는 요청 의존) | 구글·빙 |
| 외부 언급 경로 | 거의 없음 | GitHub 답글(하루 1)·Discourse(AI 표시) |

## 3. 제안 (재판에 올릴 안)
### KO 전략 — "적게, 고유하게, 네이버 병행"
- **KO-1 공개 상한**: 12/02 측정 규칙은 그대로 둔다(<30%면 3편만, 82편 1월). 1월 재개 때도 **하루 1편 상한**. 공개 전 [조사] 비교에서 "경쟁 페이지에 없는 빈틈 ≥1"(공식 신규 발표·직접 실행값 등)이 확인된 글만 공개한다. 없으면 보류한다.
- **KO-2 빠진 글**: 삭제·noindex는 하지 않는다(11/27 유죄 판결, 공식 "삭제는 최후 수단"). 개선은 12월 업데이트가 끝나고 1주 비교를 한 뒤에, 과거 노출이 있던 글부터 하루 2편 이하로 한다. 업데이트 중에는 예약(미공개) 글만 고친다.
- **KO-3 네이버**: 12/01 site: 확인 뒤, 11/25부터 멈춘 네이버 수집 요청을 하루 15편 한도로 다시 할지 판단한다(Yeti가 요청에만 반응했기 때문). 다음(Daum) 가입은 사용자 몫이다.
### EN 전략 — "되는 것을 키운다"
- **EN-1**: 하루 1편 예약(75편) 유지, 실측 출력 필수.
- **EN-2 언급 늘리기**: 공개 글이 직접 답이 되는 GitHub 이슈 답글(하루 1, 공개·AI 표시)과 ROS Discourse 답글(AI 표시, 하루 3·9:1 규칙)을 매일 찾는다. 공식 문서가 권하는 "홍보·언급" 경로다.
- **EN-3**: EN 새 글 중단(11/22 결정)은 유지한다. 예약분이 2.5개월 있다.
### 공통
- **C-1**: GSC 요청 주 1회 유지. IndexNow·사이트맵·lastmod를 색인 수단으로 기대하지 않는다(발견용).
- **C-2**: 12/02 08:30에 Search Status를 원문으로 확인한다. 12월 배포가 시작됐으면 11/26 규칙대로 KO 0편. 사전 예고만이면 색인률 규칙대로.
- **C-3**: 판정 숫자는 언어별로 따로 본다. KO 색인률(생활)과 EN 색인률을 주 1회 각각 기록한다.

## 4. 하지 않을 것
- 사이트 단위 noindex·대량 삭제(유죄 판결), 제목·날짜만 바꾸기, Indexing API, 업데이트 중 공개 글 대량 수정, 허용되지 않은 채널 게시.
