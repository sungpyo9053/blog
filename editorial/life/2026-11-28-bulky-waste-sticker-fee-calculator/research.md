# 대형폐기물 스티커(배출 수수료) 가격 2026 — 리서치 노트

- 자료 확인일: 2026년 11월 8일
- 방식: curl(일반 브라우저 UA)만 사용, 브라우저 미사용. 원본은 /tmp/bw1108에 받았다가 삭제했고 evidence/에는 필요한 행만 발췌.
- 국가법령정보센터 자치법규: `https://www.law.go.kr/자치법규/{조례명}` → `ordinSeq` → `LSW/ordinInfoR.do?ordinSeq=` 본문에서 별표 첨부(`flDownload.do?flSeq=`) 링크 → HWP/HWPX 다운로드 → `tools/hwp2rows.py`(표 셀 주소 기준 행 추출, olefile 사용은 /tmp 가상환경에서만)로 행 단위 텍스트화.
- 별표 미리보기(`ordinBylContentsInfoR.do`)는 "미리보기가 지원되지 않습니다"라서 첨부 원본 파일을 직접 파싱했다.
- 표준 품목 8개(장롱 폭 90cm 1쪽 / 2인용 침대 매트리스+틀 / 2인용 매트리스만 / 3인용 소파 / 4인용 나무 식탁 / 한쪽서랍 책상 / 냉장고 500ℓ급 / 세탁기 10kg급)로 맞춰 옮겼고, 각 구 별표의 실제 품목·규격 문구를 계산기 결과에 함께 표시한다. 분리 가격만 있는 구는 매트리스+틀을 더했고, 30cm당·1인당 방식은 90cm·3인 기준으로 곱했다(계산식은 라벨에 명시).

- 중랑구: 조례 첨부는 종량제봉투 가격(별표2), 시행규칙(2019.3.7.) 첨부에도 대형폐기물 표 없음 → 확인하지 못했다.
- 성남시·용인시: 조례 첨부에서 대형폐기물 별표를 찾지 못함. 화성시·인천 남동구·부산 해운대구·대구 달서구·광주 북구: 조례명 조회 실패. 세종·대전 서구·청주·전주는 별표를 받았으나 이번 글에는 넣지 않았다.
