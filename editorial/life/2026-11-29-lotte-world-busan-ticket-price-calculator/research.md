## 수집 방법 (curl only, 브라우저 미사용)

- adventurebusan.lotteworld.com 은 React SPA라 HTML(3,531 bytes)에 본문이 없다. 번들 `/assets/index-D3ep9n3k.js`(3.2MB, 보관 안 함)에서 API 경로와 `webSiteId="HC01806"`을 찾았다.
- 화면 문자열은 `getLocale$1(key, fallback)` 로 그리며, sessionStorage의 locale 데이터(= API `GET /api/common/locale-list?seCode=advb-ui&langCd=HC01701`)에 키가 있으면 그 값을 쓴다. 번들 fallback(어른 1Day "47,000원", After "36,000원", 골드 "280,000원")은 옛 값이라 쓰지 않았다. API 값 49,000원은 혜택 페이지 표의 "정상가" 49,000원과 일치한다.
- 원본 JSON/JS는 /tmp/lwb1108 에 받은 뒤 필요한 줄만 evidence/ 에 텍스트로 남기고 삭제.
