접수유의사항

  • 결제관련문의
  • 본인인증
  • 전자결제 창에서 결제 기관이 안보이는 경우
  • 대한상공회의소 자격평가사업단에서의 온라인 검정시험접수는 토스페이먼츠의 시스템을 사용하여 결제를 진행하고 있습니다.
    전자결제 창에서 결제하려는 기관이 보이지 않는 경우 토스페이먼츠 고객센터(1544-7772)로 문의하시기 바랍니다.
  • 전자결제 창에서 카드, 계좌 비밀번호를 잊어버린 경우
  • 대한상공회의소 자격평가사업단은 수험자님의 카드 또는 계좌번호의 비밀번호를 알 수 없습니다.
    비밀번호를 확인하기 위해서는 결제수단의 은행이나 카드사에 문의하시기 바랍니다.
  • 전자결제 창에서 계좌이체 시 보안카드가 오류인 경우
  • 대한상공회의소 자격평가사업단은 수험자님의 계좌정보를 알 수 없습니다다.
    수험자님의 계좌정보와 연동된 보안카드를 확인하기 위해서는 해당 은행에 문의하셔야 합니다.
  • 휴대폰 소액결제가 되지 않은 경우
  • 휴대폰 소액결제를 진행하기 위해서는 한도나 소액결제 가능여부 등을 확인하셔야 합니다.
    소액결제 진행을 위해 이용 중이신 휴대폰의 통신사나 휴대폰 소액결제사인 다날 고객센터에 문의하시기 바랍니다.

    다날 온라인 문의
  • 바이러스 및 악성코드에 감염되어 있을 경우 (무료검사)
  • 실명인증 방법(국가기술자격)

  •   국가기술자격종목 : 워드프로세서, 컴퓨터활용능력, 비서, 전자상거래관리사, 전자상거래운용사, 전산회계운용사, 한글속기

    1. 개별인증


    상단메뉴의 [단체접수] - [정기시험접수] - [개별인증]을 클릭합니다.

    2. 개별인증 유형선택


    국가기술자격 체크박스를 클릭하고 [확인] 버튼을 클릭합니다.

    3. 인적사항 확인


    주민등록번호 항목에 주민번호를 입력하고 [주민번호확인] 버튼을 클릭하여 본인인증을 완료합니다.

    ※ 실명인증이 안되는 경우
    간혹 정상 정보를 입력했음에도 실명확인이 되지 않는 경우가 있습니다.
    고객님의 실명정보가 NICE평가정보㈜에 존재하지 않은 경우로 초고령자, 미성년자 또는 금융거래 실적이 전혀 없는 경우에는 데이터 등록이 안되어 있을 수 있습니다. 이럴 경우 실명등록을 하게되면 정상적인 실명확인이 가능하며, 한번 등록이 되면 추후 재등록을 하실 필요가 없습니다.
    실명등록이란?
    실명등록이란 고객님의 실명정보가 NICE평가정보㈜에 존재하지 않은 경우 별도의 등록절차를 거쳐 실명정보와 인증키를 등록하는 것을 말합니다.
    실명등록방법
    ㆍ1999년 이후 발급된 주민등록증이 있는 경우
      주민등록번호, 성명, 발급일자를 홈페이지 일반실명등록 신청화면에서 입력하시거나, 이메일로 보내주시면 정상여부 확인 후 등록

    ㆍ1999년 이후 발급된 주민등록증이 없는 경우
      주민등록등본 등 증빙서류를 우편 또는 팩스, 이메일로 보내어 정상여부 확인 후 등록

    ㆍ외국인인경우
      외국인의 실명정보는 법무부 출입국 사무소의 외국인 등록DB를 통해 관리되며, NICE평가정보㈜에 별도의 등록절차가 존재하지 않습니다.
      일반적으로 출입국사무소를 통해 외국인등록증을 발급받게 되면, 2~3일정도 경과 후 외국인 실명정보 조회가 가능합니다.
  • 실명인증 방법(국가기술 이외의 자격)
  • 실명인증 안내(국가기술 이외의 자격)

      국가기술 이외의 자격 관련하여 본인 인증방법으로는 휴대폰 본인 인증과 I-PIN 인증이 있습니다.

    1. I-PIN 인증

    [I-PIN인증]탭에서 [I-PIN인증] 버튼을 클릭하면 인증화면으로 새창이 실행됩니다.



    I-PIN 신규발급, ID/비밀번호찾기 및 관리는 I-PIN 모듈창에서 처리가 가능합니다.
    I-PIN 관련 업무는 NICE평가정보(주) 고객센터(1600-1522)로 문의하시기 바랍니다.
    I-PIN 인증 후 상단 [개별접수] 메뉴를 통하여 원서접수를 진행하실 수 있습니다.

    2. 휴대폰 인증

    [휴대폰 인증]탭에서 [휴대폰 인증] 버튼을 클릭하면 인증화면으로 새창이 실행됩니다.



    이용 중이신 통신사를 선택하여 본인 휴대폰으로 인증을 진행합니다.
    휴대폰 본인 인증 후 상단 [개별접수] 메뉴를 통하여 원서접수를 진행하실 수 있습니다.
