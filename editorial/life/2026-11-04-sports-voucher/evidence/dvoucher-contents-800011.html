개인이용권 안내

  • 지원 대상 : 「장애인복지법」에 따른 등록 장애인

    지원연령 : 5세 ~ 69세 장애인

  • 지원 내용

    장애인스포츠강좌이용권 가맹시설 이용 시 1인당 매월 11만원 범위내 스포츠강좌 수강료 지원 (복수강좌)

    1인당 지원기간 : 12개월

    이용기간에 매월 사용하지 않은 지원금은 자동 소멸되며, 다음달로 이월하거나 현금으로 인출 불가

  • 개인이용권 신청기간

    1차 : 전국 동시접수 (신청기간 모집공고 참조)

    2차 : 기초자치단체별 모집현황에 따라 자율적으로 추가 접수

  • 개인이용권 신청방법

    온라인 신청 : 장애인스포츠강좌이용권 홈페이지(dvoucher.kspo.or.kr) 회원가입 후 [개인회원] 메뉴에서 신청

    서면 신청 : 신청자 주민등록상 관할지역의 시·군·구청을 방문하여 서면 신청

  • 신청주체

    지원대상자 본인 및 가구의 가구원 또는 그 친척, 기타 관계인
    - 시설보호(거주) 학생은 시설장이 학생별로 신청(서면신청)
    - 지원대상자 및 가구원이 외국인 등록번호를 받은 경우에도 신청 가능(서면신청)

  • 개인이용권 신청/선정절차

    1. 개인이용권 신청

    2. 대상자 선정
      시·군·구청에서 지원대상자 선정
      신청결과는 홈페이지,
      알림톡(문자) 확인
    3. 카드 발급
      장애인스포츠강좌이용권 전용카드발급(신한카드)
      (온라인)회원이 URL 통해 직접 신청 ·발급
      (유선)카드사에서 회원에게 전화안내·발급

  • 선정기준

    선정기준-선정순위,누적이용기간,수급자격

    법정 한부모 가족

    3순위 19세 이상 차상위 계층, 법정 한부모 가족

이용권신청 방법
이동순서 1. 개인 회원가입 → 2. 로그인 → 3. 개인 이용권신청 → 4. 신청내역 확인 → ※이용권 간편신청 안내

1. 개인 회원가입

01. 회원가입 클릭 01-1. 홈페이지 메인 화면에서 우측 상단의 회원가입을 클릭하세요. 02. 개인 회원가입 클릭 02-1.개인회원 가입을 위해 개인 회원가입 버튼을 선택하세요. 03. 이용약관 동의 03-1. 회원약관, 개인정보수집이용, 개인정보수집이용, 제3자 정보제공, 민감정보수집이용, 신한카드 개인회원 약관 승인 및 준수 내용을 확인 후 우측 상단의 전체동의 또는 각 항목의 동의를 선택하세요. 03-2. 약관 내용에 모두 동의하셨으면 화면 하단의 동의 버튼을 클릭하세요. 04. 본인인증-법정대리인 동의 및 본인인증 04-1. 본인인증 동의 후 휴대폰 인증 또는 아이핀 인증을 선택하여 본인인증을 진행해주세요. 본인 인증수단이 없는 경우 대리인(보호자) 동의 후 휴대폰 또는 아이핀 인증을 선택해 진행할 수 있습니다. 04-2. 신청인의 이름과 주민등록번호를 입력 후 수급자격 확인버튼을 클릭하세요. 05. 본인인증-수급자격 조회 05-1. 신청인의 이름과 주민번호를 입력 후 수급자격 조회 확인 버튼을 클릭하세요. 06. 본인인증-수급자격 선택 06-1. 조회결과가 적격으로 뜬 항목 중 신청하고자 하는 수급자격을 선택하세요. 07. 본인인증-수급자격 결과 확인 07-1. 선택한 수급자격 정보가 맞는지 확인하세요. 07-2. 수급자격 결과 확인 후 하단의 다음단계 버튼을 클릭하세요. 08. 회원정보 입력-기본정보 입력 08-1. 회원정보 상세 내용을 입력하세요. 09. 회원정보 입력-선택정보 09-1. 알림톡(문자), 이메일수신 동의 여부를 선택하세요. 동의하지 않는 경우 알림톡(문자) 및 이메일이 오지 않습니다. 09-2. 모든 내용을 올바르게 입력 후 다음단계 버튼을 클릭하세요. 10. 회원가입 완료 10-1. 개인 회원가입이 완료되었음을 확인하세요. 10-2. 개인 이용권신청 바로가기 버튼 클릭 시 로그인 후 개인 이용권신청을 바로 시작할 수 있습니다.

2. 로그인

01. 로그인 클릭 01-1. 우측 상단의 로그인을 클릭하세요. 02. 아이디,비밀번호 입력 02-1. 아이디와 비밀번호를 입력하세요. 02-2. 로그인 버튼을 클릭하세요.

3. 개인 이용권신청

01. 개인 이용권신청 메뉴 선택 01-1. 상단 메뉴에서 개인회원 하위 개인이용권신청 메뉴를 클릭하세요. 02. 신청지역 및 신청기간 확인 02-1. 로그인한 사용자인 경우 회원정보의 거주지역을 기준으로 신청지역을 안내합니다. 02-2. 해당 지역이 신청기간인 경우 이용권 신청 버튼을 클릭하세요. 02-3. 신청지역을 조회하여 선택하고 싶은 경우 거주지의 시/도를 선택하고, 시/군/구를 선택하면, 하단 리스트에 신청지역이 조회됩니다. 02-4. 해당 지역이 신청기간인 경우 이용권 신청 버튼을 클릭하세요. 03. 이용약관 동의 03-1. 장애인스포츠강좌이용권 부정〮불성실 사용 처리기준 내용을 확인 후 우측 상단의 동의를 선택하세요. 03-2. 내용에 동의하셨으면 화면 하단의 동의 버튼을 클릭하세요. 04. 상세정보 등록-기본정보 04-1. 선택한 신청지역이 표시되며, 변경할 수 있습니다.(신청지역은 거주지여야 하며, 신청가능기간만 선택할 수 있습니다.) 04-2. 수급자격 확인 버튼을 클릭하여, 팝업창이 뜨면 신청하고자 하는 적격 항목 중 하나를 선택하세요. 05. 상세정보 등록-신청자 정보 05-1. 신청자 정보 항목을 모두 입력하세요. 05-2. 장애유형을 선택하시면 스포츠강좌 신청 시 관련 강좌를 추천 받을 수 있습니다. 06. 상세정보 등록-세대주 정보 06-1. 세대주 이름과 주민등록번호를 입력하세요. 06-2. 세대주 정보조회 버튼을 클릭하여 세대주 등록 가능 여부를 확인하세요. 07. 상세정보 등록-카드 발급자 정보 07-1. 카드를 발급할 대상을 선택하고 이름과 주민등록번호를 입력하세요. 07-2. 카드발급자 정보조회 버튼을 클릭하여 카드발급자 가능 여부를 확인하세요. 08. 상세정보 등록-선택항목 08-1. 알림톡(문자), 이메일수신 동의 여부를 선택합니다. 동의하지 않는 경우 알림톡(문자) 및 이메일이 오지 않습니다. 08-2. 모든 내용을 올바르게 입력 후 신청하기 버튼을 클릭하세요. 09. 이용권 신청 완료 09-1. 개인이용권 신청이 완료되었음을 확인하세요. 09-2. 이용권 신청내역 확인 버튼 클릭하면 마이페이지로 이동하며, 신청하신 내역을 확인하거나 수정할 수 있습니다.

4. 신청내역 확인

01. 강좌이용권 신청현황 메뉴 선택 01-1. 상단 메뉴에서 마이페이지 하위 강좌이용권 신청현황 메뉴를 클릭하세요. 02. 강좌이용권 신청정보 확인 02-1. 이용권 신청정보를 확인하세요. 02-2. 상세 내용을 확인하거나 수정/삭제를 하시려면 신청정보 보기 버튼을 클릭하세요. 신청정보 보기에서 이용증명서를 발급 받을 수 있습니다.

※ 이용권 간편신청 안내

이용권 간편신청은 기존 이용권 선정자가 다시 신청할 경우 전년도 이용권 신청 정보를 자동으로 입력 받아 동일한 정보를 입력해야 하는 번거로움 없이 간편하게 개인 이용권을 신청할 수 있는 기능입니다.

01. 개인 이용권신청 메뉴 선택 01-1. 상단 메뉴에서 개인회원 하위 개인이용권신청 메뉴를 클릭하세요. 02. 간편신청 안내창 확인 02-1. 전년도 장애인스포츠강좌이용권을 사용했던 회원일 경우 위와 같은 안내창이 뜨며, [확인] 버튼을 선택하세요.  03. 개인 이용권신청 상세정보 등록 화면 03-1. 개인 이용권신청 상세정보 등록 화면으로 이동하며, 전년도 신청 정보가 자동으로 입력되어 있습니다.
수강신청 방법
이동순서 1. 강좌 선택하기 → 2. 카드 결제하기 → 3. 수강신청 확인 및 결제 취소

1. 강좌 선택하기

01. 개인 수강신청결〮제 메뉴 선택 01-1. 상단 메뉴에서 개인회원 하위 개인이용권신청 메뉴를 클릭하세요. 02. 최근 이용강좌 확인 및 수강신청 02-1. 최근에 이용한 강좌가 있는 경우 화면 상단에 표시되며, 재수강 하시려면 수강신청 버튼을 클릭하세요. 03. 시설 및 강좌 검색 03-1. 시설을 이용할 지역의 시/도, 시군구를 선택하세요. 03-2. 원하는 강좌종목, 장애유형, 편의시설을 선택하세요. 03-3. 검색어로 조회하고 싶은 경우 시설명 또는 주소를 입력하세요. 03-4. 검색 버튼을 클릭하면 하단에 시설 정보가 표시됩니다. 04. 시설 확인 04-1. 검색 결과 목록에서 원하는 시설을 확인 후 강좌보기 버튼을 클릭하세요. 05. 강좌 수강신청 05-1. 시설 상세정보에서 개설 강좌정보를 확인 후 원하는 강좌의 수강신청 버튼을 클릭하세요. 06. 결제금액 확인 06-1. 선택한 강좌의 결제금액을 확인하고, 결제하기 버튼을 클릭하세요.

2. 카드 결제하기

01. 결제창에서 약관 동의 01-1. 나이스페이먼츠 결제창에서 약관에 동의 후 다음 버튼을 클릭하세요. 02. 신한카드 선택 02-1. 신한카드를 선택하고 할부조건을 선택한 후 다음 버튼을 클릭하세요. 03. 일반결제 선택 03-1. 상단의 다른결제를 클릭 후 일반결제를 선택하세요. 04. 결제금액 확인 04-1. 카드번호와 CVC 번호를 입력 후 다음 버튼을 클릭하여 결제를 완료하세요. 05. 결제완료 확인 05-1. 강좌결제가 완료되었음을 확인하세요. 05-2. 수강신청현황 확인 버튼 클릭하면 마이페이지로 이동하며, 결제하신 내역을 확인하거나 결제 취소를 할 수 있습니다.

3. 수강신청 확인 및 결제 취소

01. 수강신청 결제내역 메뉴 선택 01-1. 상단 메뉴에서 마이페이지 하위 수강신청 결제내역 메뉴를 클릭하세요. 02. 결제 강좌 확인 및 결제취소 02-1. 결제한 강좌 정보를 확인하세요. 02-2. 결제취소를 원할 경우 결제취소 버튼을 클릭하세요. 03. 결제취소 요청 03-1. 개인회원 결제 취소요청 가능기간을 확인하세요. 취소 가능 기간이 지나면 결제를 취소할 수 없습니다. 03-2. 결제취소요청 버튼을 클릭하면 시설주에게 결제취소 요청이 전달됩니다. 시설주가 결제취소요청을 승인하면 결제가 최종 취소됩니다.
주의사항 및 문의처

  • 신청 시 주의사항

    신청대상 자녀가 2명 이상인 경우, 해당 자녀 모두 회원가입 후 개별적으로 신청
    - 예) 신청대상 자녀가 3명인 경우 : 자녀1, 자녀2, 자녀3을 각각 신청(각각 회원가입 후 신청횟수 총 3회)

    반드시 각 신청자별로 실제 주민등록상의 거주지 1곳만 신청 가능
    - 타 거주지역 또는 2개 이상의 지역에 대해 신청하시면 지원대상으로 선정되지 않거나, 선정되더라도 취소처리 됩니다.

    세대주가 외국인인 경우 거주하시는 시·군·구청 담당자를 통해 신청 가능(홈페이지 신청 불가)

  • 이용 시 주의사항

    결제 후 적절한 사유없이 월 출석일 수 50%이상 결석할 경우
    - 해당 월의 다음 달부터 지원 중단 가능

    이용자가 당해년도 지원기간 중 미결제 발생 시
    - 당해년도 지원기간 중 누적 2회 이상 미사용자 : 지자체 판단에 따라 중단 가능
    - 당해년도 지원기간 중 연속 3개월 미사용자 : 자동 지원중단

    이용자(또는 보호자∙가구원 등)와 강좌시설의 담합에 의해 현금화할 경우
    - 카드 사용정지 및 해당금액 환수
    - 이용자 지원 중지 및 강좌시설 선정취소 (당해연도 및 향후 2년)
