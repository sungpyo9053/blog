답례품 선택

  • 01.상단 회원가입 버튼을 선택하여
    약관동의 페이지가 열리면
  • 02. 이용약관과 개인정보 수집ㆍ 이용동의, 알림서비스 수신 동의를 체크한 후 확인을 누릅니다
  • 03. 금융인증서 또는 휴대폰인증을
    통해 본인 인증을 진행합니다
  • 04. 아이디 입력 후 중복확인을 해 주세요
  • 05. 비밀번호 규칙에 따라 X표시된 항목 전체가 체크 표시로 변경되어야 회원가입이 정상적으로 진행됩니다 
  • 06. 휴대폰번호와 이메일, 주소등 필수입력정보를 입력합니다
  • 07. 회원등록 버튼을 클릭하면 회원가입이 완료됩니다
  • 08. 약관 동의 후 다음 또는 카카오톡 인증 버튼을 클릭해 회원가입 하실 수도 있습니다

아이디 로그인

  • 01. 상단 로그인버튼을 선택하여 로그인 창이 열리면 아이디 로그인 탭에서
  • 02. 회원가입시 등록한 아이디·비밀번호를 입력 후 로그인을 진행해 주세요

카카오톡·네이버 인증 로그인

  • 01. 상단 로그인 버튼을 선택하여 로그인 창이 열리면 아이디 로그인탭에서
  • 02. 카카오톡·네이버인증 버튼 클릭 후
  • 03. 카카오톡·네이버인증 로그인 창이 열리면 카카오톡·네이버 아이디와 비밀번호를 입력하여 본인인증 후 로그인이 됩니다

금융·간편인증 로그인

  • 01. 상단 로그인 버튼을 선택하여 로그인 창이 열리면 금융·간편인증 로그인 탭에서 
  • 02. 금융인증서 로그인 혹은 간편인증 버튼을 클릭합니다
  • 03. (금융인증서 로그인 선택시) 창이 열리면 인증에 필요한 정보를 입력하고 인증을 진행하면 로그인이 됩니다
  • 04. (간편인증 로그인 선택시) 창이 열리면 인증에 필요한 정보를 입력하고 인증을 진행하면 로그인이 됩니다

자치단체 기부하기

  • 01. 고향사랑e음에 로그인 후 기부하기를 클릭합니다
  • 02. 주민번호 뒷자리를 입력하고 거주지를 확인합니다(거주지 이외의 자치단체에만 기부할 수 있습니다)
  • 03. 주민번호 뒷자리를 입력하고 거주지를 확인합니다(거주지 이외의 자치단체에만 기부할 수 있습니다)
  • 04. 기부금액을 입력(선택)하고 답례품 제공여부를 선택합니다
  • 05. 전체동의 후 기부하기 버튼을 클릭하면 기부금액 결제로 이동합니다

특정사업 기부하기

  • 01. 고향사랑e음에 로그인 후 기부하기를 클릭합니다
  • 02. 주민번호 뒷자리를 입력하고 거주지를 확인합니다(거주지 이외의 자치단체에만 기부할 수 있습니다)
  • 03. 기부할 자치단체를 선택하고 특정사업에 기부하기탭을 클릭합니다
  • 04. 기부하고자 하는 관심 특정사업을 선택합니다
  • 05. 기부금액을 입력(선택)하고 답례품 제공여부를 선택합니다
  • 06. 전체동의 후 기부하기 버튼을 클릭하면 기부금액 결제로 이동합니다

서울시에 기부하는 경우

  • 01. 이택스 납부화면 창에서 3가지 납부방법 가운데 하나를 선택 합니다
  • 02. 선택한 납부 방법별로 결제를 진행합니다
  • 03. 납부가 완료되면 확인을 클릭해 주세요
  • 04. 고향사랑e음 사이트에서 완료 안내창이 열리면 마이페이지 바로가기 링크를 클릭하여 기부내역을 확인합니다

15개 시도에 기부하는 경우 – 서울시 제외

  • 01. 납부시스템 팝업창이 뜨면 납부시스템 약관에 전체동의를 체크하고 확인 버튼을 누릅니다
  • 02. 납부방법 중 하나를 선택합니다
  • 03. 결제정보를 입력하고 다음 버튼을 클릭합니다
  • 04. 납부결과에서 납부 완료내용 확인 후 확인 버튼을 눌러 주세요
  • 05. 고향사랑e음 사이트에서 완료안내창이 열리면 마이페이지 바로가기 링크를 클릭하여 기부내역을 확인합니다 

결제 중단 후 다시 결제하는 경우

  • 01. 메인페이지 상단의 마이페이지를 클릭합니다
  • 02.기부내역을 클릭하여 기부내역 조회화면으로 이동합니다
  • 03. 기부지역과 기부금액 등을 확인하고 “다시 기부하기”를 클릭합니다(이후 절차는 “결제하기”절차와 동일합니다)
  • 01. 고향사랑e음에 접속하신 후 상단의 마이페이지를 눌러 기부포인트를 클릭합니다
  • 02. 기부하신 자치단체의 포인트나 답례품몰 보러가기 버튼을 클릭합니다
  • 03. 기부 자치단체의 답례품몰에서 보유 포인트 범위 내의 답례품을 선택하고 바로선택 버튼을 클릭합니다
