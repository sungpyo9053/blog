모바일 신분증 사용자

모바일 신분증 온·오프라인
어디서나 간편하게 사용하세요!

실물 신분증을 사용할 수 있는 모든 곳에서
모바일 신분증을 사용 가능합니다.

다양한 곳에서 모바일 신분증을 활용해보세요.

활용예

편의점, 술집 은행 관공서 공공웹사이트

  • "성인이세요?"

  • 앱에서 "나의 QR" 선택

  • QR을 스캔

  • 성인여부 확인

  • "신분증 보여주세요"

  • 은행에서 QR제공

  • 내 휴대폰으로 QR을 스캔

  • 본인확인 완료

  • "신분증 보여주세요"

  • 앱에서 "나의 QR" 선택

  • QR을 스캔

  • 본인확인 완료

  • 웹사이트 로그인 필요

  • 웹사이트에서 QR제공

  • 앱에서 QR을 스캔

  • 인증 완료

※ 앱 화면을 터치해 신분증을 제시하면 육안 확인도 가능해요.

    언제, 어디서나 하나로

    오프라인과 온라인에서 따로 소지하고 관리하는 불편함이
    모바일 신분증 하나로 편리해집니다.

    필요한 정보만 제출

    기존 신분증에서 개인정보가 불필요하게 노출되는
    사생활 침해로부터 보호합니다.

    온라인에서 신분증 스캔 없이

    온라인에서 신분증 제출 시 매번 스캔하는 번거로움 없이
    모바일 신분증은 간편하게 사용할 수 있어요
