## 수집 방법 (curl only, 브라우저 미사용)

- adventure.lotteworld.com 은 Vite/React SPA라 HTML(3,305 bytes)에 본문이 없다. 페이지 번들 `/assets/index-CrU6ru4r.js`를 받아 페이지가 호출하는 API를 찾았다.
- 가격 문자열은 번들의 `useLocale("PRICE.TICKET.ALL.1DAY.ADULT","62,000원")` 형태로 들어 있으나 두 번째 인자는 **기본값(fallback)**이다. `useLocale=(o,a)=>{... const et=_e.filter(tt=>tt.chrctrCode===o);return et.length>0?et[0].chrctrNm||"":a}` 로, 실제 화면 문자열은 API `GET /api/common/locale-list?seCode=adv-ui&langCd=HC01701` 결과가 덮어쓴다. 번들 기본값(62,000원 등)은 옛 가격이라 쓰지 않았다.
- storeCd `HC01801`(webSiteId), langCd `HC01701`(한국어)는 번들의 `webSiteId="HC01801"`, `getInitialLang` 에서 확인.
- 원본 JSON/JS는 /tmp/lw1108 에 받은 뒤 필요한 줄만 evidence/ 에 텍스트로 남기고 삭제.
