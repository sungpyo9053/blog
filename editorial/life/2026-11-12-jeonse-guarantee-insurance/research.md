## 계산 규칙 (계산기에 넣은 것)
- 주택가격: 시세 입력 그대로, 공시가격 입력 시 ×1.4 (HUG·HF 공통 140%).
- 주택가액 = 주택가격 × 0.9.
- HUG: 보증금 ≤ 7억(서울·경기·인천)/5억; 보증금+선순위 ≤ 주택가액; 선순위 ≤ 주택가액×60%. 부채비율=(선순위+보증금)/주택가액 → 70% 이하/80% 이하/80% 초과. 요율 = 표[보증금 구간][아파트 / 그 외 전부 '기타'][부채비율]. 보증료 = 보증금×요율×일수/365. 선순위 > 주택가액×50%면 기본 보증료의 10% 할증. 할인 40/60%는 기본 보증료에 곱해 따로 표시(할인·할증 적용 순서는 원문에 없음 → 확인하지 못했다).
- HF: 주택가격 ≤ 12억; 한도 = min(지역 한도, 주택가액−선순위); 보증금 ≤ 한도; 선순위 ≤ 주택가액×60%. LTV=(선순위+보증금)/주택가격 → 0.04/0.11/0.18%, 90% 초과는 불가. 보증료 = 보증금×요율/365×일수 (윤년 366은 미반영 — 본문에 안내 원문 그대로 인용).
- SGI: 사용자가 입력한 요율로 같은 산식만 계산, 요건 판정 없음.
- 계약기간 일수 = 종료일 − 시작일 + 1 (HUG 예제 2018.1.1.~2019.12.31. = 2년 = 730일과 맞춤).
- 원 단위 반올림(기관의 끝자리 처리는 확인하지 못했다).
- 본문 예: HUG 3억/시세 5억/아파트/선순위 0 → 부채비율 66.7% → 0.107% → 730일 642,000원. HF 같은 조건 LTV 60% → 0.04% → 240,000원. 공시가 2억 빌라 → 주택가격 2.8억, 한도 기준 2.52억(126%). 공시가 1.5억 → 1.89억.
