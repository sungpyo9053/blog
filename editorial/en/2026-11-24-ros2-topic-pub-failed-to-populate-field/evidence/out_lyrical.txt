Publish a message to a topic

positional arguments:
  topic_name            Name of the ROS topic to publish to (e.g. '/chatter')
  message_type          Type of the ROS message (e.g. 'std_msgs/String')

options:

  --stdin               Read values from standard input
  --yaml-file YAML_FILE
                        YAML file that has message contents, e.g STDOUT from
                        ros2 topic echo <topic>
  -r, --rate N          Publishing rate in Hz (default: 1)
  -p, --print N         Only print every N-th published message (default: 1)

                        flag is not set meaning the subscriber will wait
                        endlessly.
  --keep-alive N        Keep publishing node alive for N seconds after the
                        last msg (default: 0.1)
  -n, --node-name NODE_NAME
                        Name of the created publishing node
  --qos-profile {unknown,default,system_default,sensor_data,services_default,parameters,parameter_events,action_status_default,best_available,rosout_default}

                        (default: default)
