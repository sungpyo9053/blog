제목: 로컬 LLM, RAM 8GB·16GB 노트북이면 몇 B 모델까지 될까 — Ollama로 27번 직접 측정
"내 노트북으로 로컬 LLM 돌릴 수 있나?" 감으로 답하지 않고 쟀습니다. Ollama로 Qwen2.5 3B·7B·14B를 RAM 상한 4GB·8GB·16GB에서 세 번씩, 모두 27번 돌렸습니다. GPU 없이 CPU만 쓴 결과입니다.

■ 결과 (스왑 끔, RAM 안에서 끝났는지)
- RAM 4GB: 3B만 성공(최대 3.6GiB). 7B·14B는 메모리 부족으로 종료
- RAM 8GB: 3B·7B 성공. 7B 최대 6.2GiB. 14B는 종료
- RAM 16GB: 14B까지 성공. 단 최대 13.6GiB로 거의 꽉 참

■ 속도 (CPU 4코어, 초당 토큰)
- 3B 약 5.4 / 7B 약 2.6 / 14B 약 1.3
- RAM을 늘려도 속도는 거의 그대로입니다. 메모리는 "돌아가느냐", 속도는 CPU가 정합니다
- 14B는 100단어 답 하나에 1~2분이라 대화용으로는 느립니다

■ 내 노트북 기준으로 고르면
- OS·브라우저가 3~4GB를 쓰니 8GB 노트북은 3B로 시작
- 7B를 편하게 쓰려면 16GB
- 14B는 32GB
- RAM 슬롯이 있는 노트북은 모듈만 바꾸면 되고, 맥북처럼 납땜된 모델은 살 때 정해야 합니다
