# Purpose-built educational example

교육용 산술 모델에서 /clock 갱신의 편도 통신 지연을 L초, 현실 1초 동안 진행하는 시뮬레이션 시간을 배속 R, 지연 중 진행한 논리 시간을 D=R×L초로 둔다. 모든 사례는 일정한 R과 L, 동일한 시계 기준, 계산 구간 중 정지·역점프·지연 변동이 없다고 가정한다. 20ms는 0.02초로 바꿔 계산한다. 1배·10배·50배는 배속 효과를, 10ms 사례는 지연 감소 효과를, 0배는 일시정지 경계를 비교하려고 골랐다. 마지막 사례는 허용 논리 시간 차이 0.1초와 지연 0.02초에서 가능한 최대 배속 후보를 계산한다. 각 결과는 측정된 동기화 오차가 아니라 메시지가 이동하는 동안 시뮬레이션 시간이 얼마나 진행할 수 있는지를 나타내는 제한된 비교값이다.

통신 지연이 0.02초로 같아도 배속이 1, 10, 50으로 커지면 모델의 논리 시간 진행량은 0.02초, 0.2초, 1초로 증가한다. 10배속에서 지연을 절반으로 줄이면 진행량도 0.1초로 줄며, 허용 차이가 0.1초라면 20ms 지연 조건의 최대 배속 후보는 5배다. 독자는 자신의 예상 지연과 허용 차이를 넣어 배속 상한 후보를 계산한 뒤 /clock 발행 빈도와 실제 지연을 별도로 검증해야 한다.

이 예제는 ROS 2 노드나 시뮬레이터를 실행한 벤치마크가 아니며 실제 /clock 오차의 보장 상한도 아니다. DDS 지터, 발행 주기와 양자화, 처리·스케줄링 지연, 여러 노드의 수신 시점 차이, 초기화 전 0, 패킷 손실, 일시정지 직전의 전파, 순방향·역방향 시간 점프를 모델링하지 않는다. 0배속 사례도 이미 전송 중인 갱신의 거동을 증명하지 않는다. 계산값만으로 로봇 제어 주기나 안전 timeout을 정할 수 없으며, 하드웨어 timeout은 ROS 시간과 분리된 단조 시간 사용 여부를 검토해야 한다.
