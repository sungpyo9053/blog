# Purpose-built educational example

길이는 미터, 시간은 초, 속도는 m/s, 가속도는 m/s²로 둔다. 초기 위치와 속도는 0이고 가속도는 2m/s²로 1초 동안 일정하다고 가정한다. 각 단계에서는 먼저 이전 속도×시간 간격을 위치에 더하고, 이어 가속도×시간 간격을 속도에 더하는 단순 전진 계산을 사용한다. 0.5초와 0.25초를 고른 이유는 총 모사 시간 1초를 각각 2단계와 4단계로 정확히 나눠 계산 빈도의 영향만 비교하기 위해서다.

이 모형에서는 시간 간격을 0.5초에서 0.25초로 줄이자 1초 뒤 위치 오차가 0.5m에서 0.25m로 줄지만, 최종 속도는 두 계산 모두 2m/s다. 따라서 한 출력이 같다는 사실만으로 전체 시뮬레이션이 정확하다고 판단할 수 없으며, 독자는 자신의 모사에서 시간 간격을 절반으로 바꾼 뒤 위치 같은 관심 출력의 차이를 비교해야 한다.

이는 일정 가속도와 특정한 단계 갱신 순서만 사용하는 산술 교육 모형이며 로봇 벤치마크나 실행 결과가 아니다. 관절 질량행렬, 중력 변화, 마찰, 접촉, 제어기, 센서 오차와 에너지 보존을 계산하지 않는다. 시간 간격을 줄이면 이 예제의 위치 오차가 감소한다는 점만 보여 주며, 실제 로봇의 안정성·정확도·안전성이나 모든 적분법의 오차 감소율은 추론할 수 없다.
