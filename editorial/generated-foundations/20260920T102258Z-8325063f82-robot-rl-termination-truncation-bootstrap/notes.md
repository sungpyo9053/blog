# Purpose-built educational example

실제 로봇이나 환경을 실행하지 않는 제한된 산술 모델이다. 보상 r과 상태가치 V의 단위는 환경이 정한 무차원 보상 단위, 할인율 γ와 종료 마스크는 무차원이라고 둔다. 공통 계산은 r + γ × (1 - terminated) × V이며, 비교용 잘못된 계산은 terminated와 truncated를 합친 done을 대신 넣는다. 기준 입력 r=1, γ=0.9, V=10은 미래 가치 항 9가 눈에 잘 드러나도록 골랐다. 음의 보상 사례는 절단을 실패로 오해할 때 목표값의 부호까지 바뀔 수 있음을 보여준다. 각 expected는 학습 성능이 아니라 주어진 식의 목표값이다.

추락 같은 과제 내 종결에서는 목표값이 즉시 보상만 남지만, 외부 시간 제한 절단에서는 다음 상태 가치까지 더해야 한다. 독자는 학습 코드에서 done 하나로 부트스트랩을 끄는 부분을 찾아, 동일한 보상·할인율·다음 가치에 대해 종결과 절단의 기대값이 달라지는 단위 테스트를 작성해야 한다.

이 예제는 주어진 보상·할인율·다음 상태 가치로 한 단계 목표값만 계산한다. 가치 추정의 정확도, 정책 학습, 수렴, 로봇 제어 성능, 환경 실행 결과를 검증하지 않는다. 과제 정의에 포함된 유한 지평의 종료와 외부 래퍼의 시간 제한은 구분해야 하며, 실제 코드에서는 사용하는 Gymnasium 버전과 환경이 반환하는 terminated·truncated 의미를 확인해야 한다.
