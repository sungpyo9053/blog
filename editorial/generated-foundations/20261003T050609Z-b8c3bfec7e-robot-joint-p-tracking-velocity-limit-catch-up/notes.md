# Purpose-built educational example

속도를 직접 명령받는 이상적인 단일 관절을 산술로 따라가는 교육용 모델이다. 로봇 벤치마크가 아니다. 단위는 각도 rad, 속도 rad/s, 게인 Kp는 1/s, 시간 s다. 오차는 e = 목표 각도 − 실제 각도로 두고 양수 방향만 다룬다. 목표는 일정한 속도 c로 움직인다. 출처(Modern Robotics 11.3 Part 1)에서 가져온 것은 P 제어 θ̇ = Kp·e(Kp > 0)와, 포화가 없을 때 정상상태 오차가 c/Kp라는 결과다. 출처가 '최대 속도에 걸리면 단순 선형 모델이 맞지 않는다'고만 말한 부분에는 교육용 가정을 하나 더한다. 명령 속도 Kp·e가 vmax를 넘으면 실제 관절 속도는 정확히 vmax가 된다는 가정이다. 그러면 오차 변화율은 ė = c − min(Kp·e, vmax)다. 숫자는 vmax = 2 rad/s, Kp = 8 1/s, 처음 오차 e0 = 1 rad를 기본으로 골랐다. 경계 오차 vmax/Kp가 0.25가 되고 모든 중간값이 이진 부동소수점으로 정확히 표현되도록 하려는 선택이다. c는 네 가지로 바꾼다. 여유가 큰 0.5, 최대 속도에 가까운 1.5, 최대 속도와 같은 경계 2, 최대 속도를 넘는 반례 2.5다. 마지막으로 Kp를 32로 올린 반례를 넣어, 선형 공식이 주는 예측과 실제로 낼 수 있는 속도를 비교한다.

c ≤ vmax이면 정상상태 오차는 여전히 c/Kp다. 그때 필요한 명령 속도는 항상 c 자신이므로 포화 없이 유지된다. 다만 처음 오차가 경계 vmax/Kp보다 크면, 포화된 동안 오차는 vmax − c의 속도로만 줄어든다. 같은 1 rad 오차에서 0.25 rad까지 내려가는 시간이 정지 목표에서는 0.375초, c=0.5에서는 0.5초, c=1.5에서는 1.5초로 늘어난다. c가 vmax와 같으면 포화 구간에서 오차가 줄지 않는다. c가 vmax를 넘으면 오차가 초당 c − vmax씩 계속 커지고, Kp를 32로 올려도 이 증가율은 바뀌지 않는다. 이때 c/Kp = 0.078125 rad라는 값은 2.5 rad/s의 명령을 요구하므로 이 관절에서 실현할 수 없는 예측이다. 따라서 이동 목표를 추종할 때는 Kp를 바꾸기 전에 c와 vmax를 먼저 비교한다. c가 vmax에 가깝거나 넘으면 게인이 아니라 목표 궤적의 속도를 조정할 대상으로 본다.

포화 구간에서 관절이 정확히 vmax로 움직인다는 가정은 출처에 없는 교육용 가정이다. 출처는 속도 한계에서 선형 모델이 맞지 않는다고만 경고한다. 가속도 한계, 토크 입력, 관성, 마찰, 중력, 제어 주기, 통신 지연, 센서 노이즈, 드라이버의 한계 처리 방식(잘라내기인지 오류로 멈추는지)은 모델에 없다. 따라서 실제 따라잡는 시간은 계산보다 길 수 있고, 얼마나 길어지는지는 이 계산으로 알 수 없다. 단일 관절, 양의 오차, 일정한 목표 속도만 다뤘다. 여러 관절이 동시에 포화되는 경우, 목표 속도가 변하는 궤적, 진동과 안정 여유, 실제 장비의 안전한 게인은 이 계산으로 정할 수 없다. 숫자 vmax=2, Kp=8·32, c 값들은 설명용이며 특정 로봇의 사양이나 권장 값이 아니다. 실물 관절에 적용하기 전에는 제조사의 속도·가속도·토크 제한과 비상 정지 수단을 먼저 확인해야 한다.
