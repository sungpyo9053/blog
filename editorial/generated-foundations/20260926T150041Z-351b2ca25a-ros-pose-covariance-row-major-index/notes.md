# Purpose-built educational example

REP-103의 6차원 공분산 표현(행우선 6×6, 순서 x, y, z, X축 회전, Y축 회전, Z축 회전, 36칸)과 3×3 선형 가속도 공분산(행우선 9칸)을 인덱스 산술로 옮긴 교육용 모델입니다. 인덱스는 0부터 세며 '행×열 개수+열'로 계산합니다. 위치 단위는 m, 각도 단위는 rad(REP-103의 SI 규약)이고, 분산의 단위는 m²와 rad²입니다. 입력을 고른 기준은 다음과 같습니다. 인덱스 0과 35는 첫 칸과 마지막 대각 칸, 인덱스 1과 6은 x-y 공분산의 대칭 쌍입니다. 인덱스 14는 변수 순서를 착각했을 때 yaw 값이 들어가는 칸을 보여 주는 반례입니다. 표준편차 0.05 m와 2도는 제곱 변환을 보여 주려고 고른 설명용 수치이고, 마지막 사례는 도² 값을 rad² 칸에 그대로 넣었을 때의 배율입니다. 원주율은 이름을 쓸 수 없어 3.141592653589793 리터럴로 적었습니다. 이 수치들은 특정 센서의 사양이 아닙니다.

원하는 칸은 '행×6+열'로 찾습니다. yaw 분산은 35번, x 분산은 0번, x-y 공분산은 1번과 6번에 같은 값이 들어갑니다. 공분산 행렬이 대칭이라 행우선과 열우선을 혼동해도 결과는 같습니다. 반면 변수 순서를 착각하면 yaw 불확실성이 z 칸(14번)으로 가고, 도 단위를 라디안으로 바꾸지 않으면 분산이 약 3283배((180/π)²)로 커집니다. 따라서 테스트는 대각 인덱스 0, 7, 14, 21, 28, 35의 각 칸에 어느 변수가 들어가야 하는지, 각도 값이 rad²인지를 확인하도록 짜야 합니다. 표준편차 2도에 해당하는 rad² 분산은 약 0.00122입니다.

이 계산은 REP-103이 정한 배열 배치와 SI 단위를 옮긴 산술일 뿐입니다. 공분산 값 자체가 센서의 실제 불확실성을 잘 반영하는지, 행렬이 양의 정부호 조건을 만족하는지, 비대각 공분산을 어떻게 추정하는지는 알려 주지 않습니다. 쿼터니언으로 적은 자세와 고정축 회전 공분산 사이의 관계, 공분산이 어느 좌표 프레임 기준인지, 특정 메시지 타입이나 필터 패키지가 이 값을 어떻게 소비하는지도 다루지 않습니다. ROS 노드, 센서 드라이버, 로봇을 실행해 확인한 결과가 아니며, 원주율 리터럴 때문에 마지막 두 값에는 부동소수점 반올림 오차가 남을 수 있습니다.
