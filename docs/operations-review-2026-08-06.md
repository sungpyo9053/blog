# 2026-08-06 HuntLab 운영 리뷰

## 결론

현재 가장 큰 병목은 글 생성이나 공개 발행이 아니라 `성숙 글의 검색 진입`과
`내부 테스트가 섞인 GA4 측정`을 정확히 분리하는 일이다. 공개 사이트의 기술적
차단은 확인되지 않았고, 지금 기존 글을 일괄 수정할 근거도 없다.

이번 리뷰에서는 콘텐츠 정책을 변경하지 않고 Analytics 보고서의 분모 오류만
수정한다. Search Console 데이터 종료일 기준 발행 후 3일 이상인 글만 검색 퍼널
비율에 포함하며, 최신 글과 공개 발행일을 확인하지 못한 글은 제외한다.
