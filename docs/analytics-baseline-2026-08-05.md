## URL 통합 검증

- `http://www.huntlab.app/`은 `https://huntlab.app/`으로 2회 리디렉션 후 HTTP 200
- RSS UTM 변형도 HTTPS apex로 리디렉션됨
- 주민등록 사실조사 UTM 페이지의 canonical은 UTM이 없는 기본 글 URL을 가리킴

Search Console에 남은 `http`, `www`, UTM URL은 현재 공개 설정 오류로 단정하지 않고
과거 신호가 통합되는지 관찰한다.
