# AdSense 품질 보강 일정

기준일: 2026-08-09

목표는 AI 사용 흔적을 숨기는 것이 아니라, 기존 글에 실제 근거와 독자에게
유용한 판단을 추가하는 것이다. 애드센스 재검토 중에는 대규모 구조 변경과
일괄적인 본문 자동 수정을 하지 않는다.

## 1단계: 후보 선정과 백업

- 공개 글 감사 결과와 Search Console 노출·클릭 데이터를 함께 본다.
- 실증 근거가 약한 후보 중 보강 가능한 글 5개만 선정한다.
- 각 글의 제목·본문·메타·canonical을 변경 전 백업한다.
- 실제 작업 기록이나 1차 출처가 없는 글은 보강 대상에서 제외한다.

## 2단계: 근거 보강

- 한 번에 한 글만 수정한다.
- 검증 환경, 버전, 실행 명령, 핵심 결과, 실패 또는 한계 중 실제로 확인된
  항목만 추가한다.
- 출처와 직접 관찰을 구분하고, 경험·성능·성과를 창작하지 않는다.
- 수정 후 Reviewer 재검수와 공개 URL HTTP 200을 확인한다.

## 3단계: 탐색 정리

- 빈 `Politics` 카테고리가 실제로 필요한지 확인한다.
- 대체 글이나 내부 링크가 없으면 삭제보다 메뉴·사이트맵 노출 여부를 먼저
  확인한다.
- 깨진 링크, canonical, robots, sitemap을 함께 재감사한다.

## 4단계: 배포와 관찰

- 로컬 테스트 통과 후 커밋·푸시하고 서버는 동일 커밋을 pull한다.
- 01시 Analytics, 02시 발행, 12시 재시도 타이머는 유지한다.
- 배포 후 공개 감사에서 요약·작성자·대표 이미지·ALT·내부 링크를 확인한다.
- Search Console과 AdSense 심사 결과가 나오기 전에는 동일 글을 반복 수정하지
  않는다.

## 중단 조건

- 근거를 실제로 확인할 수 없거나 기존 글과 중복되는 경우 `HOLD`한다.
- 수정으로 제목·검색 의도·canonical이 바뀌면 별도 재검수한다.
- 공개 URL, sitemap 또는 발행 파이프라인에 회귀가 생기면 즉시 롤백한다.
