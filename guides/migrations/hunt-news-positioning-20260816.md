# Hunt News 포지셔닝 마이그레이션

기준일: 2026-08-16

## 목표

표시 브랜드를 `Hunt News`로 바꾸고 사이트의 목적을 다음 한 문장으로 통일한다.

> 복잡한 변화가 내 생활에 어떤 영향을 주는지 쉽게 설명합니다.

도메인 `huntlab.app`, 기존 게시물 URL, 게시물 ID와 미디어는 유지한다. 기존 글을
일괄 삭제하거나 날짜만 갱신하지 않는다.

## 활성 카테고리

| 표시 이름 | slug | 범위 |
|---|---|---|
| 생활 | `life` | 교통, 주거, 건강, 교육, 소비, 공공서비스 |
| 경제 | `economy` | 금리, 물가, 세금, 보험료, 에너지 가격, 가계 영향 |
| 부동산 | `real-estate` | 전월세, 청약, 대출 규제, 세금, 정비사업, 거주 선택 |
| 사회 | `society` | 제도, 노동, 복지, 안전, 인구, 권리 |
| 정치 | `politics` | 법안, 예산, 선거 제도, 행정 변화의 생활 영향 |
| 문화·엔터 | `culture-entertainment` | 콘텐츠, 공연, 방송, 플랫폼, 계약, 소비 변화 |
| IT | `it` | 기존 기술 글과 생활에 영향을 주는 AI·플랫폼·기술 변화 |

`깊이 보기`, `속보`, `체크리스트`는 카테고리가 아니라 태그 또는 시리즈로 쓴다.

## 기존 카테고리 매핑

| 기존 | 이동 대상 |
|---|---|
| Tech, AI, ML Algorithms, Harness Engineering, System Architecture, Build Log | IT |
| Economy | 경제(동일 slug 유지) |
| Society | 사회(동일 slug 유지) |
| Politics | 정치(동일 slug 유지) |
| Hot Issue | 글별로 생활·경제·부동산·사회·정치·문화·엔터 중 하나 |

기존 기술 카테고리 archive는 IT로 301 리디렉션한다. 게시물 permalink는 바꾸지 않는다.

## 적용 우선순위

1. **P0 파이프라인 계약:** Planner, Writer, Reviewer, Publisher가 생활·경제·부동산·사회·정치·문화·엔터·IT를 같은 이름으로 처리하도록 맞춘다.
2. **P0 안전 백업:** WordPress 글·카테고리·페이지·사이트 설정과 변경 계획을 JSON으로 백업하고 대상 수를 검증한다.
3. **P1 분류 마이그레이션:** 새 카테고리를 만들고 기존 기술 글은 IT, Hot Issue는 생활 영향 기준 분야로 재분류한다.
4. **P1 브랜드·탐색 UI:** 사이트 제목·설명·소개 페이지, 메인 hero, 영향 설명 3단계, 분야별 탐색과 최신 글 제목을 개편한다.
5. **P1 레거시 호환:** 기존 기술 카테고리 archive는 IT로 301 리디렉션하고 게시물 ID·slug·permalink는 유지한다.
6. **P2 공개 검증:** 데스크톱·모바일에서 홈, 글, 새 카테고리, 이미지, 메뉴, canonical과 GA4 요청을 확인한다.
7. **P3 발행 검증:** 새 파이프라인으로 한 글을 Reviewer 승인까지 통과시켜 실제 Publish하고 카테고리·미디어·공개 URL을 확인한다.
8. **P4 배포 확정:** 전체 회귀 테스트 후 변경 파일만 커밋·푸시하고 운영 서버 checkout과 타이머 상태를 대조한다.
9. **P5 관찰:** 다음 30일 동안 카테고리별 노출·CTR·검색 유입·참여를 비교한다.

## 중단 조건과 복구

- 백업 파일 생성과 대상 개수 검증 전에는 분류를 변경하지 않는다.
- 게시물 URL 또는 ID가 바뀌면 즉시 중단한다.
- 한 게시물이라도 카테고리가 비면 중단한다.
- 새 카테고리 archive가 200이 아니면 메뉴를 배포하지 않는다.
- 변경 전 JSON 백업과 플러그인 이전 파일을 복구 기준으로 사용한다.
