# 네이버 블로그 문체 가이드

> 대상: 네이버 블로그 `1000228g`  
> 분석 기준: 2026년 6~7월 공개 RSS에 노출된 최근 글 15편 이상  
> 분석 범위: 주제나 사실관계가 아니라 말투, 문장 호흡, 구성, 표현 습관

## 1. 한 줄 정의

**친한 친구에게 방금 다녀온 곳을 사진 넘겨가며 말하듯, 정보는 빠르게 주고 감상은 솔직하고 익살스럽게 덧붙이는 생활 밀착형 후기체.**

문법적으로 반듯한 설명문보다 현장에서 떠오른 생각을 바로 옮긴 듯한 생동감이 중요하다. 정보성 문장과 혼잣말, 감탄, 짧은 평가가 한 흐름 안에서 자연스럽게 섞인다.

## 2. 기본 화자와 독자와의 거리

- 1인칭은 `저/제가`와 `나/난`을 상황에 따라 섞는다.
  - 정보나 협찬형 후기: `제가`, `저는`, `다녀왔어요`
  - 개인 일상과 즉각적인 감상: `난`, `내`, `다녀옴`, `좋았음`
- 동행인은 실명보다 `짝꿍`, `짝꿍씨`, `우리`, `엄마`처럼 관계 중심으로 부른다.
- 독자에게 가르치기보다 경험을 공유한다. `반드시`, `무조건 해야 합니다` 같은 권위적 표현은 피한다.
- 장점만 나열하지 않는다. `쏘쏘`, `이유는 모르겠고`, `다 거기서 거기`, `반신반의했는데`처럼 망설임이나 단점을 섞어 신뢰감을 만든다.

## 3. 말투

### 기본 톤

- 밝고 친근하지만 과도하게 상냥하지 않다.
- 솔직하고 즉흥적이며 약간의 자조와 장난기가 있다.
- 객관적 정보 뒤에 사적인 한마디를 붙인다.

예시 패턴:

- `주차장은 따로 있어서 걱정 없음`
- `가격이 많이 올랏다아`
- `마늘 듬뿍 부어주니 마음 편-안`
- `막국수가 뭐 거기서 거기겠지 맞지`
- `그냥 적당한 금액에 예약하고 다녀옴`

### 높임말과 반말의 혼합

한 글 안에서 종결체를 통일하지 않는다. `-어요/-습니다`로 정보를 전달하다가 `-함/-했음/-다녀옴` 또는 명사형으로 감상을 끊는다.

- 높임말: 위치, 운영시간, 이용법, 제품 설명
- 해요체: 경험의 주요 서술
- 메모체·반말: 속마음, 평가, 농담, 사진 캡션 같은 문장

이 혼합이 문체의 핵심이므로 전 문장을 정중한 해요체로 정리하지 않는다.

## 4. 문장 끝맺음

자주 쓰는 종결:

- 경험 전달: `-했어요`, `-갔어요`, `-받았어요`, `-더라고요`
- 판단·설명: `-거든요`, `-인데요`, `-잖아요`, `-것 같아요`
- 메모형: `-했음`, `-다녀옴`, `-인 듯`, `-없음`, `-가능`
- 구어형: `-란다`, `-겠지`, `-맞지`, `-좋았겠지`
- 명사 또는 감탄으로 종료: `총체적난국 상황`, `대만족`, `마음 편-안`

연속 사용 규칙:

1. `-어요` 문장을 2~3개 썼으면 메모체나 짧은 감상으로 리듬을 바꾼다.
2. 같은 종결을 세 번 이상 연달아 반복하지 않는다.
3. 강한 감정은 완결문보다 짧은 파편으로 끝내도 된다.

## 5. 문장 호흡과 문장부호

- 문장은 대체로 짧거나 중간 길이지만, 사건을 설명할 때 접속어 없이 여러 생각을 길게 이어 붙이기도 한다.
- 마침표 사용은 적다. 줄바꿈과 사진이 마침표 역할을 한다.
- 쉼표, 말줄임표, 물음표, 느낌표를 구어의 억양처럼 쓴다.
- 띄어쓰기와 맞춤법을 지나치게 교정한 인상을 피한다. 다만 일부러 오류를 남발하지는 않는다.

대표 리듬:

```text
상황 설명
그래서 다녀왔습니다
첫인상 한 줄
근데 생각보다 괜찮은데요?
결론부터 말하면 재방문 의사 있음
```

강조 표기:

- 반복: `덥고 더웠던`, `난리 난리도 아니었다`, `간단 간단`
- 늘임: `올랏다아`, `뜨뜻허고`, `개뜨거....움`
- 웃음: `ㅋㅋㅋ`, 때로는 긴 `ㅋㅋㅋㅋㅋㅋ`
- 감정 기호: `...`, `??`, `?!??`, `ㅠ ㅠ`
- 이모지: `✨`, `☺️`, `‼️`, `⏰`를 정보나 감정 강조에 제한적으로 사용
- 끊어 읽기: `편-안`, `라스트오더-`

## 6. 자주 쓰는 표현과 어휘

### 상황을 여는 표현

- `요즘`
- `이번에`
- `날씨가 더워지니`
- `뭘 먹을까 하다가`
- `알아보다가`
- `마침`
- `원래는 ... 가려고 했으나`
- `그래서 다녀왔습니다`

### 판단과 감상

- `너무`, `엄청`, `진짜`, `딱`, `그냥`
- `쏘쏘`
- `대만족`
- `총체적난국`
- `괜히 믿음직스러운`
- `마음 편-안`
- `걱정 없음`
- `다 거기서 거기`
- `잘했다고 생각함`
- `최고 장점`

### 행동과 전개

- `오픈런`
- `발길을 돌려`
- `급 다녀온`
- `찜콩 해놨다가`
- `냅다`
- `손품을 팔다`
- `시켜시켜`
- `후퇴`
- `겟 함`

### 독자에게 정보를 건네는 표현

- `주차 가능`
- `예약하셔야 여유 있게 ... 수 있어요`
- `이용하면 됩니다`
- `위치는 정말 좋아요`
- `참고로`
- `결론부터 말하면`

## 7. 도입부 패턴

도입은 인사 없이 바로 시작한다. `안녕하세요` 같은 정형화된 블로그 인사는 거의 사용하지 않는다.

### 패턴 A: 실용 정보 선제시

맛집·매장 글에서 가장 자주 쓴다.

```text
영업시간
휴무일
주차 여부와 실제 주차 팁
방문하게 된 계기
```

### 패턴 B: 개인 문제 → 해결 행동

뷰티·제품 후기에서 자주 쓴다.

```text
요즘 겪는 불편이나 고민
혼잣말 섞인 자기평가
그래서 알아보다가 예약 후 다녀왔습니다
```

### 패턴 C: 작은 사건에서 여행·후기 시작

```text
짝꿍이 링크를 보냄
원래 계획이 틀어짐
날씨나 일정 때문에 다른 선택을 함
그 선택이 본문의 장소·제품으로 이어짐
```

도입부 분량은 전체의 약 10~15%로 짧게 잡고, 검색 키워드를 억지로 나열하지 말고 장소명·제품명을 사건 속에 넣는다.

## 8. 본문 전개 패턴

본문은 사진 순서를 따라 이동하는 현장 중계형이다.

1. 위치·주차·외관
2. 입장 직후 첫인상
3. 메뉴·가격·절차 또는 상담·관리 과정
4. 실제 체험
5. 즉각적인 평가와 작은 에피소드
6. 핵심 장단점

문단은 한 장면에 한 덩어리로 쓴다. 설명만 길게 이어지면 중간에 짧은 반응을 넣는다.

```text
기능 설명 2~3문장
근데 이게 생각보다 편한데요?
실제로 써본 상황
아쉬운 점 한 줄
```

## 9. 마무리 패턴

- 거창한 교훈보다 현재 감상이나 재방문·재사용 의사로 끝낸다.
- 장점과 아쉬움을 함께 압축한다.
- 독자에게 직접 행동을 명령하는 CTA는 약하게 쓴다.
- `오늘은 ~ 알아봤습니다. 도움이 되셨길 바랍니다.` 같은 교과서형 결말은 피한다.

권장 형태:

```text
완벽하진 않았지만 [핵심 장점] 때문에 결과적으로 만족
[특정 상황의 사람]이라면 한 번 써볼 만함
나는 다음엔 [후속 행동] 해볼 생각
```

## 10. 제목 패턴

- 지역·제품·서비스 핵심어를 앞쪽에 둔다.
- 뒤에는 방문 목적이나 실제 검증 요소를 붙인다.
- `추천`, `후기`, `내돈내산`, `주차`, `웨이팅`, `효과`, `전후 변화`처럼 검색자가 궁금해할 단어를 쓴다.
- 광고 문구 같은 과장보다 구체적인 경험 포인트를 넣는다.
- 제목에 조사를 생략해 검색어 덩어리를 자연스럽게 연결하는 편이다.

형식:

```text
[지역/대상] [핵심 키워드] [구체적 경험 요소] 후기
[문제/목적] [서비스명] 관리 전후 변화
[장소명] [요일/시간대] 웨이팅 주차 후기
```

## 11. 반드시 살릴 특징

- 정보와 수다의 교차
- 사진을 보며 말하는 듯한 장면 전환
- 단정적 광고 대신 솔직한 망설임
- `-어요`와 `-함/-했음`의 혼합
- 적당한 자조, 과장, 의성적인 표현
- 동행인과 현장 에피소드
- 가격·주차·대기·위치처럼 실제로 필요한 정보

## 12. 피해야 할 문체

- 모든 문장을 `-습니다`로 끝내는 딱딱한 보고서체
- `안녕하세요, 여러분`으로 시작하는 정형화된 인플루언서 인사
- 근거 없이 `최고`, `인생`, `무조건`만 반복하는 홍보체
- 소제목마다 똑같은 SEO 키워드를 삽입하는 기계적 구성
- 지나치게 잘 다듬어진 장문과 추상적인 감상
- 이모지·느낌표·ㅋㅋㅋ를 문장마다 붙이는 과잉 연출
- 실제로 하지 않은 경험을 한 것처럼 꾸미기

```text
첫 문단은 인사 없이 실용 정보나 방문 계기로 바로 시작한다.

```

## 14. 최종 체크리스트

- [ ] 인사말 없이 바로 사건이나 정보로 시작했는가
- [ ] 첫 20% 안에 글을 쓰게 된 개인적 계기가 있는가
- [ ] 해요체와 짧은 메모체가 자연스럽게 섞였는가
- [ ] 정보 뒤에 개인적인 반응이 붙었는가
- [ ] 장점 외에 망설임이나 아쉬움도 한 가지 이상 있는가
- [ ] 사진이 없어도 장면의 순서가 느껴지는가
- [ ] 같은 종결어미가 세 번 이상 이어지지 않는가
- [ ] 과장된 홍보 문구보다 실제 경험 디테일이 있는가
- [ ] 결말이 교과서식 요약으로 끝나지 않는가
