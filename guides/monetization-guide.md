# HuntLab 수익화 운영 가이드

이 문서는 검색 유입을 해치지 않으면서 광고·제휴·문의 전환을 설계하는 단일 운영 기준이다. 검색 의도와 독자에게 도움이 되는 콘텐츠가 수익화보다 항상 우선한다.

## 수익화 원칙

- 수익 가능성만으로 주제를 선정하지 않는다.
- 제품·가격·요금·비교 글은 공식 가격·조건 자료와 확인일을 남긴다.
- 수익, 투자, 절약을 보장하거나 과장하지 않는다.
- 제휴 링크·협찬·광고가 있으면 독자가 알아볼 수 있게 고지한다.
- 독자가 다음 행동을 선택할 수 있도록 장단점과 대안을 함께 제공한다.
- CTA는 글의 검색 의도를 해결한 뒤 한 번만 자연스럽게 제안한다.

## 허용 전환 목표

- 관련 HuntLab 글 읽기
- 공식 문서·제품 페이지 방문
- 무료 체험·뉴스레터·문의
- 합법적인 제휴 링크 클릭

## 금지

- 허위 후기·가짜 사용 경험
- 수익률·합격·성능 보장
- 제휴 사실을 숨긴 추천
- 본문과 무관한 광고 키워드 삽입
- 클릭만 유도하는 낚시성 CTA

## Agent 계약

Topic Planner는 `monetization_intent`, `conversion_goal`, `commercial_keywords`를 후보에 기록한다. Researcher는 가격·조건·공식 제휴 자료를 확인한다. Writer는 `recommended_cta`와 `affiliate_disclosure`를 본문 근거에 맞게 작성한다. Reviewer는 광고성 과장과 고지 누락을 REJECT한다. Publisher는 승인된 값을 전달할 뿐 수익화 정책을 새로 만들지 않는다.
