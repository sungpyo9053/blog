# HuntLab 편집 정책

HuntLab은 AI를 조사 정리와 초안 작성의 보조 도구로 사용한다. AI가 작성했다는
이유만으로 콘텐츠를 승인하거나 거부하지 않으며, 독자에게 유용한 고유 가치와
검증 가능한 근거가 있는지를 기준으로 판단한다.

## 작성과 검수

- Topic Planner가 검색 의도, 기존 글 중복과 HuntLab 전문 분야 적합성을 확인한다.
- Researcher가 공식 문서와 1차 자료를 우선 조사하고 출처, 확인일과 한계를 남긴다.
- Writer는 Research에 기록된 사실과 경험만 사용하며 가상의 테스트나 후기를 만들지 않는다.
- Reviewer가 사실성, 검색 의도, 고유 가치, 이미지와 발행 계약을 모두 통과한 글만 승인한다.
- 승인 후 본문이 변경되면 기존 승인은 무효가 되며 다시 검수한다.

## 작성자와 운영 환경

- 공개 작성자명은 일반 계정명 `admin` 대신 `HuntLab 편집팀`을 사용한다.
- HuntLab 편집팀은 Python·FastAPI, AWS Lightsail, Cloudflare, WordPress와 AI
  콘텐츠 자동화 시스템을 직접 구축·운영하며 그 과정에서 확인한 범위만 경험으로 쓴다.
- 공개 가능한 검증 환경은 Ubuntu 24.04, Python 3.12, WordPress REST API와
  실제 사용한 제품·런타임 버전을 글 가까이에 기록한다. 모든 글이 이 환경에서
  실행됐다고 일반화하지 않는다.
- AI가 보조한 초안은 Research 근거 대조, 실제 실행 범위 확인, Reviewer 승인과
  발행 후 공개 URL·대표 이미지 검증을 거친다.
- 경력 연수, 자격, 성과와 테스트 결과를 추정하거나 창작하지 않는다.

## 주제별 근거 기준

- Build Log·설치·튜토리얼·장애 해결은 테스트 결과, 실패 사례, 로그 또는
  설정값 중 하나 이상의 공개 가능한 실제 근거를 포함한다.
- Tech·AI·보안·제품 업데이트는 실제 테스트 또는 최소 두 개의 1차 자료를
  대조한 차이, 적용 조건과 환경별 판단을 포함한다.
- Economy·Society·Politics·Hot Issue는 공식 통계·법령·공시·당사자 원문을
  대조하고 개발자, AI, 클라우드 또는 디지털 서비스 운영과의 관련성을 설명한다.
- 직접 확인하지 못한 경험과 성과는 경험한 것처럼 표현하지 않는다.

## 발행과 발행 이후

- 하루 발행량보다 품질 기준을 우선하며 고유 가치가 부족하면 발행하지 않는다.
- 기존 글과 검색 의도가 겹치면 신규 발행보다 보강, 통합 또는 후속 관점 분리를 우선한다.
- Search Console과 GA4의 표본이 충분할 때 색인, 노출, CTR과 검색 유입을
  확인하되 분석 결과만으로 자동 발행하거나 자동 삭제하지 않는다.
- 저성과 검색 의도는 유사 글 증산보다 제목·설명·본문·내부 링크 보강 또는
  콘텐츠 통합 후보로 검토한다.
- 오류가 확인되면 출처와 변경 범위를 검토해 수정하며 중요한 변경은 감사 가능한 기록으로 남긴다.

## 이해관계와 개인정보

- 제휴·협찬이 있으면 독자가 판단할 수 있도록 공개한다.
- 인증정보, 개인정보와 비공개 운영 로그는 게시하지 않는다.
- AI 보조 사용은 편집 책임을 대신하지 않는다. 최종 콘텐츠의 정확성과
  발행 판단은 HuntLab의 편집·검수 절차가 책임진다.
