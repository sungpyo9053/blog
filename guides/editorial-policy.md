# HuntLab 편집 정책

HuntLab의 중심은 피지컬 AI의 기초·용어·원리에서 최신 개념, 프레임워크와
라이브러리의 실전 활용까지 이어지는 학습 콘텐츠다. 관련 에이전트 기초와
인식·계획·도구 사용·제어·안전도 포함한다. 범위와 후보 판단은
`guides/editorial-concept.md`, 품질 기준은 `guides/physical-ai-quality.md`를 따른다.
과거 WordPress 운영 글과 뉴스 브리핑의 기준을 새 피지컬 AI 글에 혼합하지 않는다.

## 작성과 검수

- Topic Planner는 학습 경로의 빈칸, 독자 문제와 실제 실험에서 시작한다.
  DEV.to의 피지컬 AI/에이전트 글도 발견 경로로 허용하지만 인기·RSS·검색
  신호만으로 READY를 만들지 않는다. 글마다 품질이 다르며 번역·복제하지 않는다.
- Researcher는 공식 문서·원논문·공식 저장소로 독립 확인하고 핵심 주장별로
  출처·확인일·버전·불확실성·적용 범위를 남긴다. 발견 원문을 경험 근거로 쓰지 않는다.
- Writer는 기록된 사실과 검증한 자체 예제만 사용한다. AI 초안이라는 이유만으로
  승인/거절하지 않으며 자연스러운 문체를 위해 가상의 경험을 만들지 않는다.
- Reviewer는 독자 질문·용어·선수 지식·원리·예제·고유 결론·한계와 전체 기존
  글/초안 중복 검사를 확인한다. 점수로 중대한 결함을 상쇄하지 않는다.
- 작성자와 별도의 Reviewer가 최종 본문과 증거를 평가하고 Publisher는 승인된
  산출물만 처리한다. 승인 후 본문 변경은 기존 승인을 무효화한다.
- 발행 정책 SSOT는 `guides/publisher-guide.md`다. 이 문서의 품질 목표가
  승인 해시·카테고리 검증·공개 확인을 우회하는 예외가 될 수 없다.

## 초보자에게 친절하지만 얕지 않은 설명

첫 용어는 뜻과 영문을 함께 쓰고 비유 다음에는 정확한 설명을 둔다.
수식은 변수·단위·가정과 작은 예제를, 코드는 입력·출력과 선택 이유를 설명한다.
선수/후속 링크는 실제 존재하고 관련 있는 글만 연결한다. 용어집은 보조 수단이며
독립 글은 하나의 이해/해결 단위를 완성한다. 길이·코드 블록 수·FAQ 수·이미지 수는
품질 대용 지표가 아니다. 외부 글을 참고해도 자체 질문·예제·판단을 제공한다.

## 주장 종류별 근거

- 정의·원리: 확인한 1차 자료와 직접 구성하고 검산/검토한 예제. 설명용 가상
  상황은 그렇게 표시하고 관측 결과인 것처럼 쓰지 않는다.
- 최신 개념: 기존 대비 차이, 발표일/확인일, 검증된 조건. 논문 결과는 출처를
  붙여 외부 결과임을 밝히고 자체 재현과 구분한다.
- 도구 소개·선택: 지원 환경·버전·제약을 공식 자료로 확인한다. 문서 비교는
  '문서 기반 비교'로 밝히며 실측 성능 비교로 제시하지 않는다.
- 설치·튜토리얼·장애 해결: 실행 버전/환경, 코드·입력·명령·실제 결과와
  정상/실패 판별 근거가 필요하다. 미실행 코드는 '실행 검증됨'이 아니다.
- 실험·성능 비교: 조건·기준선·측정 방법·반복/표본·변동성·실패·제한을 공개한다.
  한 번의 성공을 일반 성능 우위로 확대하지 않는다.
- 실제 로봇: 시뮬레이션·공개 데이터·실물 검증 범위를 분리한다. 하드웨어와
  안전 조건이 없으면 현실 동작 성공을 주장하지 않는다.

핵심 주장에 근거가 없거나 권리/비밀정보 문제가 있으면 `HOLD` 또는 `REJECTED`다.
근거를 생성하거나 다른 저자의 경험을 자신의 경험으로 바꾸지 않는다.

## 발행과 발행 이후

10:00 KST는 새 후보 평가 시간이다. READY가 있는 경우만 작성 → 검수 → 발행하며
KST 하루 최대 1건이다. 없으면 글을 억지로 작성하지 않고 `failed=false`,
`no_publishable_topic`으로 정상 종료한다. DEV.to 발견을 이유로 별도 발행을 늘리지 않는다.
기존 공개 글과 모든 초안의 전체 비교를 완료할 수 없으면 신규 발행을 보류한다.
검색 의도가 겹치면 기존 글 보강·통합·명확한 후속 관점을 우선한다.
기존 글 수정은 백업·변경 이유·재검수·Publisher 처리·공개 확인을 거친다.
조회수나 검색 성과만으로 자동 발행/삭제하지 않는다. 중요한 오류 수정은 정정
내역을 남긴다. 버전 변화로 재현이 불가능해진 글은 재검증 또는 보류 대상으로 삼는다.

## 작성 책임, 이해관계와 안전

공개 작성 책임은 `HuntLab 운영자`로 표시하고 소개는 `/about/`으로 연결한다.
HuntLab은 AI를 조사 정리와 초안 작성의 보조 도구로 사용하며 이 사실을 숨기지 않는다.
로봇 운영 경력·자격·장비 보유·현장 경험을 추정하지 않는다. 작성자 소개는
확인된 활동만 설명한다. AI 보조 사용은 편집 책임을 대신하지 않는다.
제휴·협찬은 공개한다. 인증정보·개인정보·비공개 로그와 라이선스가 허용하지 않는
자료를 게시하지 않는다. 실물 예제에는 안전 전제와 중단 조건을 설명하며,
안전장치를 무시하게 하거나 시뮬레이션 설정을 그대로 실물에 권하지 않는다.
AdSense 심사를 위해 AI 사용 사실을 숨기지 않는다. 내부 점수는 승인 확률이
아니며 승인·수익·전문가 인증을 보장한다고 표현하지 않는다.
