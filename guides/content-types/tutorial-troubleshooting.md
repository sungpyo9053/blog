# 실습·설치·장애 해결 유형

## 독자에게 줄 결과

독자가 동일하거나 명시된 범위의 환경에서 결과를 재현하고, 실패하면 첫 진단
지점을 찾을 수 있게 한다.

## 필수 근거

- 검증 날짜, OS·런타임·제품 버전과 선행 조건
- 복사해 실행할 수 있는 명령 또는 설정과 핵심 정상 출력
- 실제로 관측한 오류, 원인과 수정 후 확인 결과
- 위험한 변경의 백업·되돌리기 또는 적용 제외 조건

## 권장 흐름

`원하는 결과 또는 증상 → 검증 환경 → 최소 절차 → 왜 필요한가 → 실패 진단 →
수정 후 확인 → 되돌리기와 한계`

단계 수를 맞추려고 설명을 쪼개지 않는다. 명령 앞에는 목적, 뒤에는 성공 판정과
실패 시 다음 확인 지점을 둔다.

## Reviewer 거절 조건

- 환경이나 버전 없이 모든 환경에서 작동한다고 보인다.
- 실행 명령은 있지만 정상·실패 판정 기준이 없다.
- 실제로 확인하지 않은 오류 해결을 경험처럼 썼다.
- 운영 데이터 변경을 안내하면서 백업·롤백·주의 조건이 없다.
