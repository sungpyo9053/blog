# AI·ML 실험 유형

## 독자에게 줄 결과

독자가 모델 이름보다 문제 정의, 데이터, 평가 기준과 실패 비용을 먼저 보고 실제
적용 가능성을 판단하게 한다.

## 필수 근거

- 입력·레이블·예측 결과의 뜻과 학습·검증 데이터 경계
- 베이스라인, 평가 지표를 선택한 이유와 오류 비용
- 실행 환경, 주요 파라미터, 재현 절차와 관측 결과
- 데이터 누수, 표본 한계, 드리프트와 일반화하지 못하는 범위

## 권장 흐름

`문제 정의 → 데이터와 표현 → 알고리즘 직관 → 실험 설계 → 베이스라인과 결과 →
오류 분석 → 실패 조건 → 적용 판단`

합성 데이터 결과는 기술 검증으로만 표현한다. 실제 서비스 성능이나 수익 개선으로
확대하지 않는다.

## Reviewer 거절 조건

- 학습과 추론, 규칙과 학습된 구조를 혼동한다.
- 데이터 분할이나 베이스라인 없이 점수만 제시한다.
- 검증하지 않은 성능·정확도·비용 절감을 단정한다.
- 실패 사례와 적용하지 말아야 할 조건이 없다.
