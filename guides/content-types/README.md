# Hunt News 글 유형 가이드

이 디렉터리는 `guides/style-guide.md`의 공통 문체를 반복하지 않고, 글마다 달라지는
증거·구조·검수 기준만 정의한다. Topic Planner는 카테고리와 별개로 아래
`content_type` 하나를 선택한다. Writer와 Reviewer는 공통 가이드와 선택된 유형
가이드 하나만 함께 읽는다.

| content_type | 적용 가이드 | 주된 검색 의도 |
|---|---|---|
| `tutorial_troubleshooting` | `tutorial-troubleshooting.md` | 실행, 설치, 오류 해결 |
| `concept_architecture` | `concept-architecture.md` | 개념 이해, 설계 판단 |
| `system_design_case` | `system-design-case.md` | 요구사항부터 트레이드오프까지의 시스템 설계 사례 |
| `ai_ml_experiment` | `ai-ml-experiment.md` | 모델·알고리즘 검증과 선택 |
| `build_log_operations` | `build-log-operations.md` | 실제 변경·장애·운영 기록 |
| `current_affairs_policy` | `current-affairs-policy.md` | 정책·통계·이슈의 실무 영향 |
| `life_impact_explainer` | `life-impact-explainer.md` | 변화가 내 돈·시간·권리·선택에 미치는 영향 |

카테고리가 유형을 자동 결정하지 않는다. 예를 들어 `IT` 글도 설치 절차라면
`tutorial_troubleshooting`, 시스템 선택을 설명한다면 `concept_architecture`다.
하나의 글에 여러 유형을 섞지 말고 검색자가 얻으려는 주된 결과로 선택한다.
